# Ploch

The root namespace of the Ploch libraries. Nothing is declared in it directly: the command-line
packages live in the namespaces under `Ploch.CommandLine`, listed on the [API reference](index.md)
page.

> This page exists because every generated API page links the first segment of its namespace
> (`Ploch`), and DocFX does not generate a page for a namespace that declares no types of its own.
